# 高校选课系统 — AI 生成与人工修改优化标注说明

## 一、编制说明

本项目采用“AI辅助开发 + 人工二次优化”的协同开发方式完成。

开发过程中使用了 Cursor+ChatGPT  AI 编程工具生成部分基础代码与工程骨架，但实际项目并非完全由 AI 自动生成，而是在 AI 初版基础上进行了多轮人工调整、结构优化、业务修正与页面完善。

其中：

- AI生成部分

  主要负责：

  - SpringBoot 工程初始化
  - 基础 CRUD 与接口结构
  - 页面初版生成
  - 工具类与测试代码草稿

- 人工优化部分

  主要负责：

  - 业务规则修正
  - 去重逻辑完善
  - CSV/Excel真实场景适配
  - 页面布局与交互优化
  - 前后端联调
  - 异常处理与健壮性增强
  - 性能优化与代码规范统一

实际开发过程中采用：

> AI生成 → 人工检查 → 人工修改 → AI补全 → 再次人工优化

的迭代方式完成项目。

# 二、AI 生成部分（基础代码与工程雏形）

以下部分主要由 Cursor根据提示词自动生成：

| 模块       | AI生成内容                                  |
| ---------- | ------------------------------------------- |
| 工程初始化 | Spring Boot 3.x 项目骨架、Maven依赖、启动类 |
| 分层结构   | Controller / Service / Entity 基础目录结构  |
| 基础接口   | CSV导入、查询、排序等接口初版               |
| 数据对象   | `EnrollRecord`、`ApiResponse` 等实体类      |
| 页面初版   | `index.html`、基础表格展示、fetch请求       |
| 测试代码   | JUnit5 基础测试类与 MockMvc 示例            |
| 工具类     | CSV解析工具、部分Excel处理代码              |

AI生成部分主要用于：

- 提高开发效率
- 快速生成项目基础框架
- 减少重复性编码工作

但生成代码仍存在：

- 业务语义不够严谨
- 边界情况考虑不足
- UI结构简单
- 实际场景适配性较弱

因此后续进行了较多人工优化。

# 三、人工重点优化

本项目并非简单“AI一键生成”。

人工主要完成了：

## 1. 业务规则修正

尤其是：

- 去重规则
- 分类逻辑
- 多条件检索
- Excel兼容

这些均进行了人工调整。

------

## 2. 页面与交互优化

人工重新设计：

- 页面布局
- 卡片分区
- 表格样式
- 加载反馈
- 空状态提示

使页面更符合真实教务管理系统。

------

## 3. 工程规范优化

包括：

- 分层架构规范
- 统一响应结构
- 异常处理
- 日志输出
- 注释规范

增强了项目可维护性。
